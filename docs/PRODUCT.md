# 产品与画像边界

BMTI（Better Me Type Indicator）以“了解自己，探索边界，成为更好的自己”为方向，帮助用户理解“面对迷茫与改变，我偏好怎样找到方向、开始行动，以及怎样被朋友陪伴”。16个角色是故事摘要，个人偏好画像独立于是否形成角色。

## 四组概念，八端独立评分

| 维度 | 端点 | 测量含义 |
| --- | --- | --- |
| 动力来源 | V愿景 / R实效 | 个人价值与生活方向 / 具体问题与可见改善 |
| 启动路径 | T想清 / A试做 | 先了解依据 / 借可控尝试了解问题 |
| 推进节奏 | S有序 / F灵活 | 预先安排与熟悉流程 / 保留调整余地 |
| 支持方式 | I自主 / C协作 | 独自整理 / 通过可信交流整理 |

两端可以同时认同。V不表示更有理想，A不表示执行力强，S不代表能坚持，I不等于内向。能力、经济条件、精力、卡点与本轮求助意愿需要另行确认，不能从字母推导。

## 已实现的体验

昵称开测 → 按八端均衡抽题 → 0—4分、无法判断或跳过 → 服务端计分 → 个人偏好报告 → 自愿核对陪伴建议、打印、删除或重做。未提交草稿在同标签页暂存；已提交记录凭浏览器Cookie重载，不按昵称找回。

管理员口令登录后配置题量、预览题库。后台没有题文编辑、评分编辑、真实答卷浏览或权限分工界面。

## 画像怎样使用

先看每一端得分与信息是否充足，再看维度解释，最后把16个名称当作可选摘要。名称与四段偏好来源见[角色卡](research/BMTI_V02_PROFILES_VALIDATION_2026-10-28.md)。未定类型也有描述；信息不足则明确不足，不捏造完整画像。

报告中的陪伴建议是供本人核对的尝试方向，不能据此认定一种干预更适合。系统目前没有自动推送、持续催促、心理诊断、LLM解释或成长内容推荐。

## 后续验证

材料仍待真实参与者验证。沿用12—20人的探索范围，先6人题意访谈并复盘；每人完成32题、深入解释8题，轮换覆盖所有题目。先验证理解、回忆、判断与选分过程；后续再验证角色名称与回应匹配。探索性规模不能证明人格模型有效。

用户拒绝、改变目标、需要休息和现实条件不足都必须被保留。公开讨论只使用合成案例或经明确授权且去标识的信息，原始答卷不进入Git、PR或Issue。
