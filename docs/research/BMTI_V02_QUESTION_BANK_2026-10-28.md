这是一份原创偏好问卷草案，尚未完成真实用户验证。不是官方MBTI题库，不用于诊断或能力评级。

## 如何作答

回顾近三个月，在条件允许、确实有选择时，按你通常更喜欢的做法作答。选择实际偏好，不是你认为自己应该成为的样子。没有相关经历时不必强行设想。

所有题目共用以下选项：

| 选项 | 含义 |
| --- | --- |
| 0 | 完全不符合 |
| 1 | 较不符合 |
| 2 | 部分符合 |
| 3 | 比较符合 |
| 4 | 非常符合 |
| U | 没有相关经历／无法判断 |
| — | 跳过 |

每题独立选择。两种看似不同的做法可以同时高分；U和跳过都不计为0分。下面按维度归类，便于审阅和挑题；正式试测建议按原题号N01—N32交错呈现，并隐藏维度说明。
