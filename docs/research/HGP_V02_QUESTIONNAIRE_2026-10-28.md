# HGP v0.2：八端独立评分题本（32题）

日期：2026-10-28。题本版本：HGP-0.2。状态：待认知访谈的研究草案，非临床或标准化人格测验。

配套：[偏差审查与旧题追溯](HGP_V02_AUDIT_2026-10-28.md)、[画像与访谈流程](HGP_V02_PROFILES_VALIDATION_2026-10-28.md)。v0.1的16题A/B答案不能换算为本版分数；本版不覆盖旧版原文。

## 1. 作答说明

> 请回顾近三个月的相关经历，在条件允许、确实有选择时，按你通常更喜欢的做法回答。问的是偏好，不是你做得多好，也不是你觉得自己应该怎样。
>
> 如果某种安排只是工作、经济、照护或时间条件所迫，请不要直接把它当成自己的偏好。没有经历或无法分清时可以选“没有相关经历／无法判断”，也可以跳过。不必假想一个资源完全充足的自己。
>
> 每题独立评分。你可以既喜欢自己整理，也喜欢与可信的人交流；既重视意义，也重视实际改善。不需要为了得到一个角色而选边。

| 选项 | 数值或处理 |
| --- | --- |
| 完全不符合 | 0 |
| 较不符合 | 1 |
| 部分符合 | 2 |
| 比较符合 | 3 |
| 非常符合 | 4 |
| 没有相关经历／无法判断 | 缺失，记录原因类别为unable |
| 跳过 | 缺失，记录原因类别为skipped |

“部分符合”是可作判断的中间回答，不替代无法判断。“完全不符合”是有效0分，不是缺失。关于共同活动的题目，仅按与自己认可的可信对象相处的经历作答；没有这种经历时不用设想必须找人。

## 3. 八端定义与题号

| 端点 | 仅用于本题本的定义 | 源题号 |

## 4. 计分和摘要规则

每端有效分仅为整数0、1、2、3、4；unknown、unable、skipped及未填写不得填成0。实际题本只提供unable与skipped，人工录入未填写时保留为未填。非法数值、布尔值和不明文字应要求核对，不静默截断、取整或转成有效答案。

每端有3或4个有效答案时，计算这些有效值的算术平均；少于3个有效答案时，均值不发布，显示“信息不足”及有效题数。每端记录缺失原因，不据此推断态度或人格。展示均值最多两位小数，分类使用未舍入的均值。

每组的判断按以下顺序，前项优先：

1. 任一端信息不足：显示“信息不足”，字母为?，即使另一端很高也不补字母。
2. 两端均值都≥3：显示“并重”，字母为?。例如3与4仍是并重，不用差值强选。
3. 两端均值都≤1：显示“这组描述目前较少符合”，字母为?。例如1与0仍不强选。
4. 其余情况下，第一端均值减第二端均值≥1：显示第一端相对侧重及其字母。
5. 其余情况下，第二端均值减第一端均值≥1：显示第二端相对侧重及其字母。
6. 其余：显示“暂无明显侧重”，字母为?。

两端绝对分与相对侧重一起展示。例如V=2、R=1时显示“相对更侧重V”，不能称“高度愿景型”。双高表示两种描述都符合，不是能力更强；双低不是动力低或能力差，只是本组文字较少符合。

只有四组均形成明确字母，才组合为16角色之一。其余显示如V?SI的摘要，说明哪些组并重、较少符合、接近或信息不足，不给最近角色。八个分数保留，不压成四个差值；不把?算成第17类人格。

阈值3、1、差值1及每端至少3题是首版产品约定，未经统计验证。题意访谈阶段不为提高完整角色比例调整阈值。跨版本分数、字母变化不能解释为成长或退步。

## 5. 独立陪伴核对（不计分）

这些问题在32题作答及认知追问之后再问，避免提前暗示应该得到哪种结果。不是额外人格题，不反向修改角色，也不要求每题选择。

| 编号 | 核对问题 | 记录方式 |
| --- | --- | --- |
| P01 | 在你愿意获得建议时，你想先听意义与方向、具体改善、两者，还是看情况？ | 原话或自选偏好，允许其他答案。 |
| P02 | 遇到不熟悉的问题，你希望朋友先解释、先示范一次、一起试，还是先问你？ | 本人明确选择，不从T/A自动推算。 |
| P03 | 讨论下一步时，你喜欢有限步骤、灵活选项、两者，还是当次再决定？ | 不从S/F自动推算。 |
| P04 | 你什么时候愿意一起梳理，什么时候更希望自己待一会儿？ | 支持时机可随情境变化，不从I/C自动推算。 |
| P05 | 这一次你想听我说说、帮你理清，还是拉你一把？有什么现实条件需要先照顾？ | 记录本轮意愿和条件；不写成长期人格。 |

这些是访谈问题，不表示应用已新增入口或改了求助模式。本轮要求停止、纠正和实际条件始终优先于旧画像。长期保存需另行确认，本轮研究不接入生产记忆。
