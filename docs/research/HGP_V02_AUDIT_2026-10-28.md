# HGP v0.2：题目与画像偏差审查

日期：2026-10-28。性质：基于现有文字的设计审查，不是用户研究结果或心理测量验证。

本轮入口：[32题题本及计分](HGP_V02_QUESTIONNAIRE_2026-10-28.md)、[画像与认知访谈](HGP_V02_PROFILES_VALIDATION_2026-10-28.md)。[v0.1题本](HGP_QUESTIONNAIRE_2026-10-28.md)、[v0.1产品概念](HGP_PRODUCT_2026-10-28.md)、[v0.1验证材料](HGP_VALIDATION_2026-10-28.md)原文保留；后续题意访谈以v0.2为当前研究草案，v0.1中的角色卡点推断和同次匹配试验不沿用。

## 1. 审查准则与结构调整

逐题检查：是否只指向一个偏好、是否把条件限制当成偏好、是否混入能力或道德评价、是否有两种可以同时成立的选项，以及是否只重复同一场景。对画像逐句检查是否超出答题能够支持的内容。

方法参考CDC认知访谈对理解、回忆、判断和作答过程的检查。该方法帮助识别人如何理解和回答问题；不能因完成文本审查就认定问卷有效。[CDC方法说明](https://www.cdc.gov/nchs/ccqder/question-evaluation/cognitive-interviewing.html)

| 文本中可确认的问题 | 对判断的影响 | v0.2处理 |
| --- | --- | --- |
| 每题要求在两端中选边。 | 无法区分“两端都符合”和“两端都不符合”。 | 八个端点独立评分，共32题；两端不互为反向分。 |
| 固定时段与步骤、协作与独处时机被捆绑。 | 一个答案可能由不同因素产生。 | 每题只问一种偏好；条件和支持意愿另外核对。 |
| 四字母摘要进一步描述优势与典型卡点。 | 将未测能力、困难写进个人画像。 | 角色只摘要四个相对侧重，能力描述删除，卡点另问。 |
| 多题围绕同一固定／灵活对比。 | 题数多不等于场景覆盖充分。 | 各端四题采用不同情境或切面，并保留重叠风险供访谈检验。 |

仍待验证的结构假设：V与R是否可分、T与S是否可分、A与F是否可分、I是否只是“先自己想”的T，以及C是否受信任、社交机会影响。保留字母并不证明这些维度互相独立。

## 2. v0.1全部16题逐题审查

“保留”只指保留要询问的主题，所有原A/B题均重新编写为独立评分项，不复用旧题分数。N编号见v0.2题本；对应关系是设计追溯，不是计分换算。

| 原题 | 原主题及具体问题 | 处理与理由 | 对应新题／残余风险 |
| --- | --- | --- | --- |
| Q01 | 项目吸引力：人生价值与眼前改善可能同时重要；项目投入相近不能排除资源影响。 | 拆分；保留动机主题，分别问意义与实效。 | N01、N02；需核对是否回答了“应该怎样”。 |
| Q02 | 新工具：理解原理、常见做法捆绑；经验与工具难度可能决定答案。 | 重写；分别问先了解与先尝试，不将上手速度算能力。 | N03、N04；仅有陌生工具经历者作答。 |
| Q03 | 项目安排：固定时段与固定步骤捆绑，同时可能受排班限制。 | 拆分；顺序和时段分别询问，允许没有自主安排经验。 | N05、N13、N14；固定偏好与现实限制需追问。 |
| Q04 | 犹豫时的支持：先后顺序、独处与交流混合；可能测到了T/A。 | 重写；在整理想法这一具体环节分别问自主与交流。 | N07、N08；与T端重叠仍待访谈检验。 |
| Q05 | 回顾投入：看见改善与保持意义可同时支持继续。 | 拆分；不把一次成果不足解释为缺乏理想。 | N09、N10；不询问成功次数。 |
| Q06 | 验证想法：推演和小试可以连续发生。 | 重写；分别询问对解释过程与实际尝试的偏好。 | N11、N12；两题均可高分。 |
| Q07 | 安排自在感：与Q03、Q15主题接近；固定安排不等于更有计划。 | 重写并分散情境；不逐字转成两道同义题。 | N14、N21、N22；留意是否仍只是换词。 |
| Q08 | 学技能：交流疑问和独自练习在不同阶段都适用。 | 拆分；固定到复盘环节，不把有没有伙伴当偏好。 | N15、N16；共同讨论不等于真实效果更好。 |
| Q09 | 解释原因：说话方式可能不同于实际动力；与Q01近似。 | 替换；不把对外解释风格算成动机。 | N17、N18；改问个人选择关注点。 |
| Q10 | 希望朋友解释或给办法：支持偏好与自己行动习惯混合。 | 退出人格计分；行为偏好另写，朋友怎样帮助另问。 | N19、N20；另见P02、P03，不做旧题直接换算。 |
| Q11 | 持续活动：回答“更帮助延续”可能是在评价效果或能力。 | 重写；只问对熟悉流程的偏好，不问能否坚持。 | N21、N22；不能将S解释为持续力强。 |
| Q12 | 受挫后支持：情绪容量、恢复时机与协作偏好混合。 | 从评分中移除受挫情境；情绪容量和支持时机单独核对。 | P04、P05；N23、N24只问日常复盘偏好，并非等价替换。 |
| Q13 | 建议先回答什么：实效、意义与朋友支持风格混合。 | 支持问题移出人格计分；动机部分换成日常投入。 | N25、N26及P01；不从爱听道理推断人格。 |
| Q14 | 小作品：与Q06近似；先理清构想和步骤可能混入S。 | 重写并换情境；分别问先辨明原因与在小范围试办法。 | N27、N28；风险可逆条件须清楚。 |
| Q15 | 新安排：与Q03、Q07重复；固定安排与灵活安排未必互斥。 | 替换为生活准备与计划受阻的两个切面，不问执行结果。 | N29、N30；日程可变程度仍可能影响理解。 |
| Q16 | 推进目标：定期交流与拥有自主空间可以同时需要。 | 拆分；不暗示交流有利于坚持或独处更独立。 | N31、N32；“可信对象存在”是条件，不是性格。 |

## 3. v0.2题目覆盖与待核实风险

| 端点 | 四题与不同切面 | 不能由分数推出 | 访谈优先核查 |
| --- | --- | --- | --- |
| V | N01方向价值、N09投入回顾、N17兴趣选择、N25生活安排。 | 更有理想、价值更高、更善良。 | 意义是否只是“我喜欢”，是否出现理想自我作答。 |
| R | N02解决不便、N10可见改善、N18学以致用、N26投入回报关注。 | 功利、只爱钱、缺乏理想。 | 是否把经济压力或迫切问题答成长期倾向。 |
| T | N03陌生工具、N11新观点、N19陌生任务、N27日常问题。 | 聪明、分析能力强、拖延。 | 想了解是否来自不会做、缺乏安全感，而非偏好。 |
| A | N04工具小试、N12想法检验、N20粗略作品、N28小范围排查。 | 执行力强、冲动、不思考。 | 是否仅因熟悉任务才愿意试；能否举出反例。 |
| S | N05任务顺序、N13自主时段、N21熟悉流程、N29出行准备清单。 | 自律、稳定产出、不能灵活变化。 | 顺序、时段、流程、清单是否其实属于不同偏好。 |
| F | N06任务顺序调整、N14自主时间调整、N22做法调整、N30计划受阻调整。 | 散漫、创新能力强、半途而废。 | 喜欢调整与被迫调整是否被混同。 |
| I | N07犹豫整理、N15技能复盘、N23日常回顾、N31个人目标回顾。 | 内向、孤独、拒绝帮助、独立能力强。 | 是否只是缺乏可信对象；与T端是否混淆。 |
| C | N08交流整理、N16共同复盘、N24日常对话、N32目标交流。 | 外向、依赖、擅长领导、照顾他人。 | 是否只是寻求认同或礼貌应答；是否把AI误当真人。 |

八端各四题的数量与映射可做机械检查；题意是否单一、区分是否充分只能先作文本判断，必须用受访者解释核实。相似表达和相近场景是本版残余风险，不将结构完整写成“已消除偏差”。

## 4. 画像逐类修正

| 受影响的旧描述 | 修正 | 保留方式 |
| --- | --- | --- |
| “能把共同想法整理成计划”“愿意持续积累”等优势。 | 删除能力和实际表现推断。 | 只说明更偏向意义／实效、先了解／先试、有序／灵活、自主／协作。 |
| “承担太多期待”“忘记自己的方向”“频繁换路”等卡点。 | 从16角色卡移除。 | 移入独立核对清单K01—K06，任何角色都可选择、不选择或跳过。 |
| “因此适合某种支持”的语气。 | 改为“可以试试，是否喜欢由你核对”。 | P01—P05独立记录，明确意愿优先于角色。 |
| 朝圣者、领航员、营造师等有能力暗示的名字。 | 按用户决定保留名称，但只在无名描述核对后展示。 | 明示为故事名称，不代表领导力、自律或命运；记录名称造成的误解。 |

每张新角色卡的四段摘要均用八端定义组合，源题号在画像材料中可追溯。同行角色是表达层，不是新的观察证据。

新增三份v0.2文档，保留v0.1；更新交接与任务索引。不改应用、API、数据库或生产提示词，不招募、不联系体验者、不采集真实私人资料。

文本审查已完成；机械一致性检查见交接记录。真实题意访谈、四维结构、重测稳定性、用户帮助和压力反馈均NOT_RUN。角色或题目是否“准”，本轮不能下结论。
